## How it was done
1. **Design source:** the repo's `DESIGN.md` was an older copy without the shadcn/Motion rules; the Project's
   `claude/DESIGN.md` and the "B.AI Design Mockup" canvas were used, and `DESIGN.md` in the repo is now that version
   plus a "where things are" table (§14).
2. **One API change first:** the UI draws the steps from the route data, so Gemini's second job became "write the
   one-line lead" (or the "Kaya: …" conclusion for vehicle checks) instead of full numbered steps. Fewer tokens,
   no duplicate text. The template does the same when AI is off.
3. **Theme** (`app/globals.css`): brand tokens mapped onto shadcn's variable names, `font-display` utility, one
   global blue focus ring, Leaflet controls restyled flat. Fonts via `next/font/google` (Archivo with the width axis).
4. **shadcn pieces** written into `components/ui/` and cleaned per DESIGN §7 (no shadows, 44px sizes). The shadcn
   CLI needs its online registry, which the build machine can't reach, so the files were written by hand from the
   standard new-york source; `components.json` is in place for future `npx shadcn add`.
5. **Screens:** `Chat.tsx` keeps the conversation and calls `/api/chat`; `Messages.tsx` picks a view per `kind`;
   `RoutePlan` / `RouteSteps` / `CheckAnswer` / `MapCard` / `FallbackForm` build the answers.
6. **Checked in a real browser** (Playwright, 360px): every screen, the map dialog, keyboard focus, touch sizes,
   no horizontal scroll. Fixed what showed up: Leaflet's CSS beating our flat controls, the "Kabuuan" line
   breaking inside "850 m", and the focus ring fading in from black.

### Key code
The lesson from the focus ring bug:

```ts
// Tailwind's transition-colors also animates outline-color, so the ring faded in from black.
"transition-[color,background-color,border-color]"
```
The global rule `:focus-visible { outline: 3px solid var(--focus) }` was right all along; the transition made
the first ~150ms of every focus look wrong. Measuring the real computed style in a browser found it.

## Why it was done this way
- **Structured steps instead of AI paragraphs:** the mockup and DESIGN.md want badges and placards, and drawing
  them from data means the screen can never show a route the router didn't return.
- **Alternatives considered:** keeping Gemini's full text and hiding the steps (loses the signboard design);
  showing both (duplicate text on a 360px screen).
- **Trade-offs:** native checkboxes in labels for preferences instead of shadcn `Checkbox` (simpler, same look);
  English answers get English labels, but the From/To form result defaults to Taglish.

## Concepts to learn from this
- **Design tokens**: named colors (`--ink`, `--signboard`) used everywhere, so the theme is changed in one place.
- **Client-only components**: Leaflet needs `window`, so `RouteMap` loads with `next/dynamic(..., { ssr: false })`.
- **CSS specificity / load order**: when two rules tie, the one loaded later wins; Leaflet's CSS loads after ours.
